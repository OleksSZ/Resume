Про мене

Навчаюсь на інженера програмного забезпечення в Криворізькому фаховому коледжі (спеціальність 121 — Інженерія програмного забезпечення). Основний фокус — backend на Python: FastAPI, робота з PostgreSQL напряму через SQL, парсинг даних (requests, Selenium) та їх структурування й аналіз.

Комерційного досвіду поки немає — я про це відкрито кажу. Натомість вкладаюсь у pet-проєкти, доводжу їх до робочого стану, розгортаю через Docker/Codespaces і викладаю на GitHub, щоб їх можна було реально запустити й перевірити, а не просто почитати опис.

Швидко засвоюю нову інформацію та маю аналітичний склад мислення — люблю розбиратись, як влаштовані дані та системи, а не просто змусити код "працювати".

Проєкти

Комерційного досвіду немає, тому головний доказ навичок — робочі pet-проєкти. Кожен викладений на GitHub, перший можна запустити прямо в браузері через Codespaces.

web_table_crm/

Web-table — міні-CRM у стилі Excel

Веб-CRM: реєстрація/логін, у кожного користувача — власна PostgreSQL-схема з реальними SQL-таблицями (не EAV/JSON). Можна створювати таблиці й колонки "на льоту", редагувати клітинки подвійним кліком як в Excel. Авторизація на httpOnly-кукі з CSRF-захистом. Запаковано в Docker + devcontainer — запускається одразу в GitHub Codespaces без ручного налаштування Postgres.

  • Python
  • FastAPI
  • PostgreSQL
  • Docker
  • JWT / CSRF
GitHub → Відкрити в Codespaces →
data_parser/

Парсер і структуризатор даних

Збір даних із сайтів двома підходами — через прямі HTTP-запити (requests) там, де це можливо, і через Selenium там, де потрібна імітація браузера. Зібрані дані очищуються та приводяться до структурованого вигляду для подальшого аналізу.

  • Python
  • Requests
  • Selenium
  • Data cleaning
GitHub →
crypto_terminal/

Міні-термінал для торгівлі на криптобіржі

Інструмент для ручної торгівлі: розміщення й відстеження ордерів, стакан ордерів у реальному часі, бектестинг стратегій на історичних даних за технічними індикаторами. Індикатор лише сигналізує про можливу угоду й надсилає сповіщення в Telegram — автоматичного входу в позицію немає.
